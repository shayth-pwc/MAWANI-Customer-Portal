# Current SAP Cloud Foundry deployment guidance

This project's active deployment instructions are in [V0.7.4-IAS-DB-SYNC-AND-POST-BOOTSTRAP.md](V0.7.4-IAS-DB-SYNC-AND-POST-BOOTSTRAP.md).

The earlier deployment guide was written for older releases and included obsolete admin access assumptions and API paths. For v0.7.4, use the current release note only. Existing PostgreSQL tables and IAS services must be reused; do not run `cds deploy` or provision replacement instances.
